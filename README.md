# 🔐 Password Strength Checker

A simple Python program that checks the strength of a password based on common security requirements. It analyzes the password for length, uppercase and lowercase letters, numbers, and special characters, then provides a strength rating and helpful feedback.

### ✨ Features

* Checks password length
* Detects uppercase and lowercase letters
* Checks for numbers and special characters
* Provides a password strength rating
* Gives suggestions to improve weak passwords
* Beginner-friendly Python project

### 🛠️ Technologies Used

* Python
* Conditional Statements
* Loops
* String Methods
* Regular Expressions

### 🎯 Purpose

This project was created to understand basic Python programming concepts while learning about password security and the characteristics of a strong password.

### 🚀 How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run:
   `python password_checker.py`
5. Enter a password when prompted and view the strength result.

**Note:** This is an educational project and should not be used as a production-grade password security system.
